Professional reflection

What I have learned, where I am strongest, and how I plan to grow as an IT professional.

What I have learned in this module

Studying the embedded systems engineer role in the "Move With Me" project changed how I think about technology. Before this, I saw hardware choices mainly as technical decisions. In this study, the engineers chose an ESP32 microcontroller, an ADXL345 accelerometer, LED feedback, Bluetooth Low Energy and a solar-charged battery. They made those choices because the children lived in areas without reliable internet or electricity, not because the parts were the most advanced available. That showed me that good IT work starts with understanding the people who will use it. My Java programming and networking modules teach me how to build and connect systems. This module taught me to ask who they are for, and what the users' real circumstances demand. As I develop as an IT professional, I want to design with that awareness, so that the technology I build helps close the digital divide rather than widen it.

My strongest IT professional skill

I enjoy breaking a complex problem into logical steps. In Computer Networks (CONE5111), I worked through subnetting exercises, dividing networks such as 192.168.50.0/24 into subnets and checking my answers in binary. In Java Programming, I traced insertion sort algorithms pass by pass to understand exactly how the data moves.

The skill I want to improve

I understand programming concepts like OOP, inheritance and 2D arrays, but I want to become more confident building complete projects and managing them professionally. When I ran into GitHub push and authentication errors with NetBeans, I realised version control is a skill I need to master, not just a tool I use.

How I will develop that skill

Build small Java projects regularly beyond the required practice questions. Use command-line Git for every project so I understand each step. Commit my work to GitHub consistently to build a visible record of progress. Review each project afterwards and note what I would improve.

How this portfolio supports my studies and career

It brings my work across networking, programming, mathematics and information systems into one place, so I can see my growth over time. Hosting it on GitHub Pages is itself practice in the version control skills I'm developing. For my career, it gives future employers real evidence of what I can do, which counts for more than a list of modules on a CV.
