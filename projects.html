ConsoleReport Java Application

The ConsoleReport Java application (built using Maven in Apache NetBeans) tracks and summarizes console sales across multiple South African cities. Using 1D arrays for regions (CAPE TOWN, PORT ELIZABETH, PRETORIA) and console models (PS5, XBOX, SWITCH), it maps sales figures in a 2D integer matrix. Nested loops process the matrix to format a clean console table via System.out.printf(), aggregate total unit sales per city into a separate 1D array, and evaluate which region achieved the highest sales volume (identifying PORT ELIZABETH with 9,000 units)

Durban Healthcare Network Diagram

This diagram demonstrates how a facility firewall acts as a security gatekeeper for the Durban healthcare network. At the same time, it enforces strict security rules to block external attackers attempting to access the sensitive internal EHR database server.
